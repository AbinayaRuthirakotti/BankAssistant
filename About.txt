ABOUT:     

	The Bank Assistant is a console-based Java application that emulates the essential operations of a basic banking system. Developed using object-oriented programming (OOP) principles, this project serves as a foundational tool for understanding how banking software operates, enabling efficient management of customer data and transactions. The primary goal of the system is to assist users in creating and maintaining customer accounts, as well as processing common banking activities such as deposits, withdrawals, and account inquiries.

	This application is composed of three key classes: Customer, BankService, and BankManagement, each fulfilling specific responsibilities in alignment with OOP concepts such as encapsulation, modularity, and abstraction. The Customer class is responsible for holding individual customer data, including account number, account type, name, and balance. This class uses private fields and public getter/setter methods to maintain secure and controlled access to sensitive data.

	The BankService class encapsulates all the core business logic of the application. It contains methods for creating new customers, displaying account details, searching for specific customers using their account numbers, processing deposits, and handling withdrawals. It also features a built-in logging mechanism that records every transaction into a CSV file. This log includes critical details such as the account number, transaction type (deposit, withdrawal, or display), the amount involved, the updated balance, and a timestamp. By using Java’s LocalDateTime and DateTimeFormatter classes, the application ensures that each transaction is accurately recorded in a consistent and readable format. The file handling is achieved through classes such as File, FileWriter, and BufferedWriter, which support both file creation and data appending functionalities.

	The BankManagement class acts as the user interface controller. It presents a menu-driven interface that prompts users to select from various operations, including creating new accounts, viewing all accounts, performing deposit or withdrawal actions, searching by account number, and exiting the application. The class utilizes a loop structure to continuously interact with the user until the exit option is chosen. All user input is captured using the Scanner class, ensuring that the application remains interactive and responsive.

	This project highlights the effective use of several core programming concepts including control flow (switch-case), data collection using List, file I/O operations, and time/date manipulation. It also provides insight into real-world software development techniques such as data logging, separation of concerns, and basic user input validation.

In conclusion, the Bank Assistant project not only demonstrates a structured and efficient way to manage bank accounts but also serves as a hands-on learning tool for students and beginners in Java programming. It provides a clear understanding of how data flows through an application, how services are implemented to handle business rules, and how data persistence can be achieved through external files. The project’s simplicity, clarity, and real-world relevance make it a strong candidate for academic assignments, early-stage Java development practice, or prototype-level banking software design.
